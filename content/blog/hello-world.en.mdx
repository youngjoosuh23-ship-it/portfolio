This blog publishes automatically whenever you add a `.mdx` file to `content/blog/` and push it to git.

## Writing a post

- Create `content/blog/your-post-slug.mdx`
- Add `metadata` (title, date, summary) at the top
- Write the body in markdown below it

## Adding images

Drop an image into `public/blog/` and load it with markdown syntax.

```md
![description](/blog/example.png)
```
